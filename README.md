# Лабораторная работа №1
Лабораторную работу выполнял Жулин Максим Александрович группа: 25КНТ-4
## Задание
Написать класс для работы с матрицами комплексных чисел. В классе должны быть методы, позволяющие сложить, перемножить, разделить матрицы (при возможности), транспонировать и вычислить определитель. К классу должен прилагаться консольный интерфейс, позволяющий создать матрицу и задать операцию.
## Структура проекта
Файлы:
Complex.java - реализован класс для работы с комплексным числом: сложение, вычитание, умножение, деление, модуль, вывод.
ComplexMatrix.java - реализован класс для работы с матрицами комплексных чисел: сложение, вычитание, умножение, деление, транспонирование, нахождение определителя.
UserInput.java - реализован консольный интерфейс.
## Как запустить
```
javac Complex.java ComplexMatrix.java UserInput.java
java UserInput
```
## Как пользоваться
1. Введите матрицу A: каждая строка на отдельной строке, элементы через пробел. Конец ввода: пустая строка.
2. Выберите операцию цифрой от 1 до 6.
3. Для операций 1-4 введите матрицу B так же, как A.
4. Программа выведет результат и завершится.
### Формат ввода комплексных чисел:
В числе не должно быть пробелов, пробелы могут стоять только между числами.
`1+4i`, `1-4i`, `2.5-1.5i` (алгебраическая запись комплексного числа)
`8`, `9`, `10` (только вещественная часть)
`8i`, `9i`, `10i` (только мнимая часть)
### Формат ввода матриц комплексных чисел:
Вводим комплексное число(внутри не должно быть пробелов) ставим пробел(табуляция не подходит) вводим следующее число.
Для записи следующей строки матрицы нажимаем Enter, и продолжаем писать таким же образом.
Пример:
```
1+8i 1+9i
2+10i 7+11i
```
## Ограничения
Из-за арифметики `double` в результатах возможны погрешности в последних знаках.
